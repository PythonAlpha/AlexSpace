# 🚀 Alex.dev — Personal Portfolio Website


jaja



A modern, fully responsive personal portfolio website built with pure
**HTML5, CSS3, and JavaScript** — no frameworks, no build tools, no dependencies.

![Tech](https://img.shields.io/badge/HTML5-CSS3-JavaScript-blue)
![Responsive](https://img.shields.io/badge/Responsive-Mobile--friendly-green)

---

## ✨ Features

- 🎯 **Typewriter effect** in the hero section (cycles through roles)
- 📱 **Fully responsive** — mobile hamburger menu included
- 📊 **Animated skill bars** that fill when scrolled into view
- 🧭 **Smooth scrolling** navigation with active-link highlighting
- ✉️ **Contact form** with client-side validation and status feedback
- 🎨 **Modern gradient design** using CSS variables (easy to re-theme)
- ⚡ **Zero dependencies** — vanilla code only, fast loading
